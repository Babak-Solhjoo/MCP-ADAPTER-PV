    Security & network policy
    
    
    Enforced by the server itself. Local mode binds 127.0.0.1 only and rejects foreign Host headers; deny any firewall prompt for local use.
    
    
    
      
    
        
    
        
    Network mode: the server may listen on other interfaces when started with --host. Allow it through the firewall only on a trusted (private) network and set a Host allow-list.
